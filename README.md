# Tontoo TontooUI

A Swift like UI Lib based on UIKit for making Modern Apps

## Made for TontooOS

Explore more at https://github.com/TontooOS/Libs

## Adding to Your Project

Add to your `Cargo.toml`:

```toml
[dependencies]
tontooui = { path = "/Library/System/tontooui.library" }
```
